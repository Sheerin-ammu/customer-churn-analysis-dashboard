# Customer Churn Analysis Dashboard

An end-to-end customer churn analysis project combining Python for data analysis/modeling and Tableau for interactive visualization.

## 📊 Overview

This project analyzes customer churn patterns to identify key factors driving customers to leave, using exploratory data analysis in Python and an interactive dashboard built in Tableau Public.

## 🛠️ Tools & Technologies

- **Python** — pandas, numpy for data cleaning and analysis
- **Matplotlib & Seaborn** — data visualization
- **Scikit-learn** — model training and evaluation (Logistic Regression, Ensemble methods)
- **Tableau Public** — interactive dashboard

## 📈 Dashboard

![Customer Churn Dashboard](Dashboard%201.png)

🔗 **[View the live interactive dashboard on Tableau Public](https://public.tableau.com/views/CustomerChurnAnalysisDashboard_17893031711620/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**

The dashboard includes:
- Key metrics: Churn Rate, Total Customers, Avg Monthly Charge, Total Revenue
- Churn breakdown by Gender, Contract Type, Internet Service, and Payment Method
- Interactive filters to slice data by Contract, Churn status, Internet Service, Payment Method, and Gender

## 🔍 Key Insights

- Customers on **Month-to-month contracts** churn significantly more than those on One-year or Two-year contracts
- **Electronic check** payment method shows the highest churn rate among payment types
- **Fiber optic** internet service customers churn more than DSL or customers with no internet service
